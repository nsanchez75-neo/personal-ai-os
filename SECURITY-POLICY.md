# SECURITY POLICY

## Never commit

- API keys
- passwords
- OAuth tokens
- private credentials
- private keys
- session cookies
- secrets
- sensitive personal data unless explicitly required and protected

## Least privilege

Agents receive only the tools required for their role.

## Human approval

Require explicit approval for:
- money movement
- contracts
- destructive operations
- sensitive external communications
- credential changes
- production infrastructure changes
- irreversible business actions

## Incident principle

When uncertain, stop, preserve state, and ask for human confirmation.
