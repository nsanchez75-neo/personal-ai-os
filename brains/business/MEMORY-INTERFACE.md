# BUSINESS BRAIN MEMORY INTERFACE v0.1

## Purpose

Define what Business Brain reads and writes without making native provider memory the source of truth.

## Read domains

- current project state;
- approved decisions;
- customer profiles and research;
- CRM state;
- offer/pricing versions;
- experiment records;
- financial/economic metrics;
- marketing/content performance;
- operational constraints;
- relevant knowledge.

## Write domains

### Customer memory
- validated jobs/pains/gains;
- buying triggers;
- objections;
- outcome evidence;
- segment changes.

### Commercial memory
- offer versions;
- pricing assumptions;
- sales patterns;
- channel performance;
- retention observations.

### Experiment memory
- hypothesis;
- test;
- evidence;
- result;
- confidence;
- lesson;
- model update.

### Economic memory
- CAC assumptions;
- margin assumptions;
- payback;
- capacity;
- cash-conversion observations.

## Write rules

- Never overwrite raw historical evidence.
- Preserve date and source.
- Distinguish observation from interpretation.
- Link important changes to a decision or experiment.
- Promote repeated validated learning; do not canonize isolated anecdotes.
