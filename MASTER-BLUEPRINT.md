# MASTER BLUEPRINT

**Version:** v0.1  
**Status:** APPROVED FOUNDATION

## 1. Mission

Build a portable personal AI operating system that can transform ideas and problems into informed decisions, businesses, AI systems, automations, and continuously improving workflows.

## 2. Core architecture

### AI Director
Coordinates brains, agents, skills, tools, sequence, approvals, and evaluation. It is an orchestrator, not a fourth brain.

### Three brains

#### CEO Brain
Strategy, business models, growth, pricing, finance, partnerships, negotiation, opportunities, prioritization, resource allocation, decisions, and risk.

#### AI Architect / Builder Brain
AI architecture, agents, skills, MCP, APIs, software, automation, infrastructure, databases, security, DevOps, observability, evaluation, cost, scalability, and portability.

#### Business Brain
Offer, ICP, customer discovery, product/service design, marketing, sales, CRM, pricing, operations, content, acquisition, growth, and experimentation.

## 3. Specialist agents

Initial set:
- Researcher
- Analyst
- Builder
- Marketing
- Sales
- Finance
- Evaluator

Avoid premature proliferation.

## 4. Skills layer

Reusable capabilities:
strategy, market-research, business-model, customer-discovery, product-design, sales, marketing, content, crm, financial-analysis, ai-architecture, agent-design, skill-design, mcp, api-integration, automation, prompt-engineering, software-architecture, cybersecurity, infrastructure, evaluation.

## 5. Tools layer

Web, files, GitHub, code, APIs, CRM, email, calendar, database, automation, analytics, MCP.

Tools use least privilege.

## 6. Memory

Separate:
- Personal Memory
- Business Memory
- Project Memory
- Operational Memory

Memory is explicit, structured, portable, auditable, and versionable.

## 7. Knowledge

Knowledge is separate from memory and contains documentation, research, procedures, frameworks, references, technical documentation, and business knowledge.

## 8. Workflows

Initial workflows:
- Idea → Business
- Lead → Client
- Idea → AI System

## 9. Evaluation

Required:
- brain tests
- agent tests
- skill tests
- workflow tests
- tool tests
- regression tests
- continuity tests

## 10. Human-in-the-loop

High-impact, irreversible, sensitive, financial, contractual, destructive, or externally consequential actions require human approval.

## 11. Portability

Core intelligence must remain provider-neutral and portable across OpenAI, Anthropic, Google, local models, APIs, and future providers.

Portable formats:
Markdown, YAML, JSON, Python.

## 12. Evolution

Simple → Modular → Testable → Reusable → Scalable.

Do not introduce complexity without a demonstrated need.
