# CONTINUITY TEST

## Purpose

Verify that a fresh AI can reconstruct PERSONAL AI OS without the original conversation.

## Test setup

Give a fresh AI access only to the repository.

## Required recovery order

BOOTSTRAP → PROJECT-CONTEXT → DECISIONS → MASTER-BLUEPRINT → CHANGELOG

## The AI must correctly identify

- Project name: PERSONAL AI OS
- Current version: v0.1
- Current phase: Block 0.1 — Project Foundation
- Three brains
- AI Director role
- Specialist agents
- GitHub as source of truth
- Continuity Pack
- Human-in-the-loop principle
- Portability principle
- Current state: foundation synchronized to GitHub
- Next objective: run continuity test, close Block 0.1, then begin CEO Brain

## Failure conditions

Fail if the fresh AI:
- invents decisions
- changes architecture without authorization
- confuses Business Brain with CEO Brain
- treats AI Director as a fourth brain
- cannot identify current phase
- cannot identify next action
- ignores the decision hierarchy
- assumes undocumented progress
